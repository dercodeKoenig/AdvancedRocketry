# Pitfall: Gradle UP-TO-DATE cache silently makes 10× test loops do nothing on iterations 2

## Summary
Gradle UP-TO-DATE cache silently makes 10× test loops do nothing on iterations 2-10. BUILD SUCCESSFUL + rc=0 but :testServer is UP-TO-DATE = 0 tests ran. Cache-bust each iteration: rm -rf build/{reports,test-results,tmp}/testServer. Always grep per-run 'PASSED' count and assert it matches expected pyramid (~336 server-tier).
